# Sagittal Posture Types

The four (+1 combined) non-structural sagittal posture types: [[lordotic_posture]], [[kyphotic_posture]], [[kyphotic_lordotic_posture]], [[flat_back_posture]], [[sway_back_posture]]. Each is a **pattern hypothesis** read from standing posture, to be confirmed by movement, and distinguished from structural misalignments (e.g., Scheuermann) by flexibility testing.
