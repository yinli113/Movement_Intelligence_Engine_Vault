# Functional Movement Screen (FMS)

A seven-test battery (deep squat, hurdle step, inline lunge, shoulder mobility, active straight-leg raise, trunk stability pushup, rotary stability) scored 0-3 with clearing exams. It is a **screen**, not a diagnosis.
