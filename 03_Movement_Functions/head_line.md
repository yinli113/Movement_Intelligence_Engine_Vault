# Head Line (Posture)

The vertical reference line through the external auditory meatus (or mastoid process) → acromion → lumbar vertebral bodies → promontory → slightly posterior to the hip joint axis → slightly anterior to the knee joint axis → lateral malleolus (or slightly in front of it). In good posture it overlaps the [[base_line]]. Each posture type is characterised by how the head line deviates (e.g., anterior to knee axis in lordotic posture; anterior to thoracic/lumbar/hip/knee axes in kyphotic posture).
