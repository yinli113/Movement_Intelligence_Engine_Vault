# Trunk Stability Push-up (FMS Test 6)

## Definition

The **trunk stability push-up** is a symmetrical push-up from a set hand position, screening trunk/core stability during a symmetrical pressing pattern, scored 0-3 with a spine-extension clearing exam (Gray Cook, *Movement*, Ch. 6, Ch. 9). FMS test 6.

## Why it matters

It tests reflex core stability in a loaded pattern — relevant to any sport needing trunk control under load (golf rotation, gait, posture hold).

## Source-derived model

- Hands at shoulder width (men) or chin level (women) standard; descend keeping the body rigid.
- Scored 0-3; clearing exam checks for painful spine extension.
