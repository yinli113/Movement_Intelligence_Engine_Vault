# Kyphotic-Lordotic Posture

A combined non-structural sagittal posture type where kyphotic and lordotic features coexist. Corrective logic is nuanced: in lordotic posture the abdominals are lengthened (should be shortened), yet in kyphotic posture shortening abdominals is not recommended — so the lower abdominals may need shortening while the upper abdominals are lengthened. A **pattern hypothesis**, not a diagnosis.
