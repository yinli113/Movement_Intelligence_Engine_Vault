# Kyphotic-Lordotic Posture

## Definition

**Kyphotic-lordotic posture** is a non-structural sagittal posture type combining **increased thoracic kyphosis with increased lumbar lordosis**, with body-part positions specified per the source's table (Czaprowski et al., 2018, p.5-11). It is the combined form of [[kyphotic_posture]] and [[lordotic_posture]].

## Why it matters

It shows that posture types can co-occur, so the engine must read the whole silhouette, not a single curve. It compounds the functional-organisation hypotheses of both parent types.

## Source-derived model

- Body-part positions: increased thoracic kyphosis + increased lumbar lordosis + anterior pelvic tilt + forward head.
- Functional organisation (per source table): combines the kyphotic and lordotic muscle tables — thoracic/cervical extensor and gluteal hypoactivity with pectoral/cervical-extensor and hamstring/hip-flexor hyperactivity.
- Corrective logic: address both regions — regain thoracic and gluteal stabiliser activity.
